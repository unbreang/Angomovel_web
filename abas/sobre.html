Feito em Angola

A nossa missão é simples

Queremos tornar Angola num destino turístico de referência mundial, dando aos turistas as ferramentas certas para explorar o país com confiança e segurança.

Acreditamos que o turismo bem organizado é um motor de desenvolvimento económico e cultural para Angola e para os angolanos.

🎯

🌍

Stack Tecnológico

Construído com tecnologias modernas e escaláveis

🌐

Frontend

HTML5, CSS3 e JavaScript puro com Progressive Web App. Design system customizado com tema claro e escuro.

PWA
⚙️

Backend

Node.js com NestJS framework. Arquitectura modular com autenticação JWT, guards e DTOs com validação.

NestJS + Node.js
🗄️

Base de Dados

PostgreSQL como base de dados principal com TypeORM. Redis para cache e optimização de desempenho.

PostgreSQL + Redis
🐳

Infraestrutura

Docker para containerização dos serviços. Ambiente isolado e reproduzível para desenvolvimento e produção.

Docker
🗺️

Mapas

Leaflet.js com OpenStreetMap para mapas interactivos gratuitos. Nominatim e OSRM para pesquisa e rotas.

Leaflet + OSM
💬

Tempo Real

Socket.io com WebSockets para chat em tempo real entre clientes e guias turísticos.

Socket.io
